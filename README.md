# Website_Clone_Tailwindcss
# Masynctech Website Clone (Tailwind CSS)

A responsive website clone built using **HTML** and **Tailwind CSS**, inspired by the Masynctech Coding School platform.  
This project focuses on layout structure, modern UI sections, and utility-first styling with Tailwind.

---

## 🔗 Live Preview
Example: https://resplendent-biscochitos-bfddc5.netlify.app/

---

---

## 🚀 Features

- Fully responsive layout
- Modern hero section with background image
- Navigation bar with hover effects
- Course cards and pricing section
- In-person programs section
- Location & contact details
- Clean footer with social media icons
- Built using Tailwind utility classes only

---

## 🛠️ Tech Stack

- **HTML5**
- **Tailwind CSS**
- **Font Awesome Icons**
- **CDN-based assets**
